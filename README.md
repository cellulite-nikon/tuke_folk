# 🍻 飲み会ツケ管理アプリ (Tuke Folk)

飲み会の現場で「誰が払って、誰がツケ（未払い）か」をスマホからワンタップで即座に記録し、全体の建て替え総額や人ごとの借金残高をリアルタイムで管理できるWebアプリです。

---

## ✨ 主な機能

1. **複数グループ（セッション）の切り替え管理**
   - 「大学同期」「会社の同僚」「サークル仲間」など、コミュニティごとに完全に独立したセッションを作成・切替可能。
   - 画面上部のグループ選択ピルをタップするだけで、ワンタップで素早く切り替え。
   - グループごとにメンバー一覧・飲み会履歴・ツケ残高が完全に分かれて管理されます。

2. **現場特化のワンタップ集金UI（スマホ最適化）**
   - 参加者ごとに `[全額済]` `[ツケ]` `[一部]` の大きなボタンを配置。酔った現場でも片手で即座に記録可能。
   - 「一部ツケ」は、その場で支払った金額（例：3,000円）を選ぶだけで残額（2,000円）をツケとして自動計算。
   - 遅刻や飲まない人の会費個別調整にも対応。

3. **ツケ・建て替え残高サマリー & PDF報告書出力**
   - **「現在の立替額合計」** をトップに大きく表示。
   - 人ごとの未回収ツケ総額ランキング（例：「佐藤: ¥5,000 (1件)」）。
   - タップで「どの飲み会のツケか」の内訳を展開。
   - **「📄 ツケ内訳のPDF出力・共有」** ボタン：
     - グループ共有用の綺麗な帳票ページ（A4対応）を生成。
     - スマホやPCのブラウザからワンタップで **PDF保存・印刷**、または **LINE用テキストのコピー** が可能。

4. **🎨 PDFデザインエディタ（完全自由カスタマイズ）**
   - 帳票の **HTMLテンプレート** と **CSSスタイル** をブラウザ上で自由に編集可能。
   - **リアルタイムA4プレビュー:** コードを編集すると、右側（スマホはタブ）に実際のツケデータが即座に反映されます。
   - **変数チップパレット:** `{{group_name}}`, `{{total_debt}}`, `{{member_name}}`, `{{debt_amount}}` などの変数をワンタップで挿入可能。
   - **保存 & いつでもリセット:** 保存したデザインは今後のすべてのPDF出力に自動適用され、いつでも初期状態に戻せます。

5. **返済日時の記録 & 清算（消込）機能**
   - **返済日時の指定記録:** 後日PayPay等で返済された際、返済した日時（例: 「昨日の21:30に受領」など過去日時も指定可能）を正確に記録。
   - **返済履歴の確認:** 各メンバーのツケ内訳を展開すると、未回収ツケだけでなく過去の返済履歴（日時・金額・メモ）も一覧確認できます。
   - **自動消込:** 入力された返済額に応じて、古い未払いから自動消込。

6. **👥 高密度メンバーリスト（一覧性向上 & 絞り込み検索）**
   - メンバー管理画面を1行約42pxのスリムなコンパクトリストに刷新。
   - 1画面で12〜15名以上をスクロールなしで一望可能。
   - インクリメンタル検索バーで大人数サークルでも即座にメンバーを見つけられます。

7. **🍻 幹事プール金（実費と回収済額の差額計算）**
   - **実費の手入力:** 各飲み会ごとに、実際にお店に支払った総額（実費）を手入力で記録・編集可能。
   - **余剰金の計算式:**
     - `余剰金 = (回収済み金額) - (店舗支払額)`
     - 飲み会単体、およびグループ全体の累計の両方でリアルタイム算出。
   - **🔒 完全な機密保護（PDF非表示）:**
     - 店舗支払額（実費）や余剰金は、**PDFやグループ共有用の帳票・LINE共有テキストには一切反映されません**（幹事のアプリ画面でのみ閲覧可能）。

5. **ゼロ依存・即時起動**
   - Node.jsや外部ライブラリのインストール不要（Python標準ライブラリ + SQLiteのみ）。
   - スマホのSafari/Chromeからホーム画面に追加（PWA）すれば、アプリ同様の全画面で使えます。

## 🐳 Docker / Ubuntu Server での運用（Mac mini × Tailscale）

Ubuntu Server上でDockerを使って常時稼働させる構成です。

### 1. サーバーへのデプロイ
この `tuke_folk` フォルダを Ubuntu Server に配置し、フォルダ内で以下を実行するだけです：

```bash
docker compose up -d --build
```

- **自動再起動 (`restart: unless-stopped`):** サーバーが再起動しても自動で立ち上がります。
- **データ永続化:** データベースはホスト側の `./data/nomikai_tuke.db` に安全にマウント・保存されます。

### 2. Tailscale 経由でのアクセス

#### A. Tailscale接続中のスマホからアクセスする場合
ブラウザで以下のいずれかを開きます：
```text
http://<Mac miniのTailscale IP>:8765
# または
http://<Mac miniのマシン名>:8765
```

#### B. Tailscaleアプリを入れていない人にもURLだけで開かせたい場合（Tailscale Funnel）
Ubuntu Serverで以下を1回実行するだけで、世界中からアクセスできる公式HTTPSの固定URLが発行されます：
```bash
tailscale funnel 8765
```
> 発行された `https://<マシン名>.<Tailnet>.ts.net` を後輩やメンバーに共有するだけでOKです！

## 🚀 使い方（誰でもカンタン起動 - Macローカル用）

コマンド操作は一切不要です！MacのFinderでファイルを**ダブルクリックするだけ**で使えます。

### 1. 起動方法
フォルダ内の **`ツケ管理.app`** または **`起動する.command`** をダブルクリックしてください。
- 自動的にサーバーが立ち上がり、**ブラウザが自動でパッと開きます**。
- ※何回クリックしても、古いプロセスを自動で整理して安全に起動します。

### 2. 停止方法
フォルダ内の **`停止する.command`** をダブルクリックしてください。
- サーバーが安全に停止します。

---

### 💻 コマンドラインから起動する場合（上級者向け）
```bash
./run.sh
# または
python3 server.py 8765
```

---

### 📱 スマホから使う場合
PCと同じWi-Fiにスマホを接続し、ブラウザで以下を開いてください：
```text
http://<あなたのMacのIPアドレス>:8765
```
> ※Safariの「共有」→「ホーム画面に追加」を行うと、専用アプリのように全画面で起動できます。

## 📁 ファイル構成

```text
tuke_folk/
├── server.py         # REST API サーバー（Python標準ライブラリ + SQLite）
├── nomikai_tuke.db   # データベースファイル
├── run.sh            # 起動シェルスクリプト
└── static/
    ├── index.html    # スマホ最適化SPA（UI / 操作ロジック）
    └── manifest.json # PWAマニフェスト（ホーム画面追加対応）
```
